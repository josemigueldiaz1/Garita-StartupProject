## Cómo agregar una conversación

1. Copiar `plantilla_notas.md` como `conversacion_N.md`, donde N es el número de la tabla de arriba.
2. Llenarla el mismo día, con la empresa anonimizada por tipo y región, y la persona por cargo.
3. Cambiar el estado de la tabla de arriba a "Hecha (AAAA-MM-DD)".
4. Pasar los hallazgos a la sección "Problema" del README principal: qué supuestos se confirmaron y la cita más fuerte.
